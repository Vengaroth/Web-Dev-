# Hotel Altavista · Página de reservaciones

Actividad de **Programación Web (semana 3): Hojas de estilo en cascada (CSS)**.
Licenciatura en Desarrollo de Software, Universidad IEU Online.

Página de reservaciones para un hotel ficticio. El objetivo fue aplicar estilos CSS a una estructura HTML que incluye título, encabezados, párrafos, saltos de línea, listas, imágenes, tablas, formularios y checkboxes.

![Vista de la página](captura_completa.png)

## Qué se trabajó

- **Tres formas de aplicar CSS:** externo (`styles.css`), interno (`<style>` en el `<head>`) y en línea (atributo `style`).
- **Variables CSS** (`:root`) para definir la paleta de colores una sola vez.
- **Distribución con Flexbox y Grid:** menú horizontal, secciones en dos columnas y formulario en dos columnas.
- **Selectores avanzados:** pseudoclases (`:hover`, `:focus`, `:nth-child`) y pseudoelementos (`::before`, `::marker`).
- **Formulario** con tipos de entrada específicos (`email`, `tel`, `date`), campos obligatorios (`required`), radios y checkboxes.
- **Diseño adaptable** con `@media`: en pantallas pequeñas todo se acomoda en una sola columna.
